Getting this into Shopify

No React needed

React Bits components only run inside a React app. A Shopify theme is Liquid, so every effect on this page is written in plain JavaScript on top of GSAP and Lenis.

  1. Add the three library files to the themeUpload gsap.min.js, ScrollTrigger.min.js and lenis.min.js to the theme's assets folder and load them in theme.liquid.
  2. Add one motion fileThe script at the bottom of this page becomes assets/motion.js. It is about 120 lines.
  3. Mark up the sectionsEach effect hooks onto an id or class, so it can be attached to an existing theme section or a Custom Liquid block.

Visitors who set "reduce motion" on their device get this page with no animation and normal scrolling.
